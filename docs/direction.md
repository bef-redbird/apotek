# Product direction

The delivered workspace supports an assisted pharmacist review of the next price
transition. Cito is the pharmacist's only file input. The operator maintains market
sources and prepares causal feature snapshots separately. Viewing, filtering,
notes and export read saved assessments rather than rerunning inference.

Use the retained probability-based selection policy and verified model artifacts.
Show the three-year amount model as the display reference, with six-year/full-history
estimates as sensitivity details. Keep probabilities, amount estimates, source
quality and uncertainty distinct. Do not invent intervals or claim model disagreement
is a confidence interval.

Historical review selects candidates from predictions before attaching outcomes.
Unknown outcomes remain in the fixed selection. Actual period-bound Cito evidence
and conditional reconstructions must not be conflated. Missing advance information
uses the real current-only route. Prospective status requires truthful dated context.

This is local research review, not ordering, clinical advice or a realised-profit
calculation. No online hosting, model retraining, recalibration or automatic model
promotion belongs to this delivery. Execution status is in [progress.md](progress.md);
data contracts are in [data-foundation.md](data-foundation.md).
