# Bounded freshness and monetary research

E5 extends accepted E4 and preserves all earlier artifacts and operational
configurations. Its private protocol freezes the finite matrix, chronological
boundaries, selection rules and resource limits before comparative scores.
[Progress](progress.md) records delivery; the private report records measured
successes, failures and limitations.

Only origin-time prices, classifications, attributes and peer context enter
features. Separately named next-period ABC is a conditional historical proxy or
period-bound actual report. Unpublished prices, later ABC, future membership,
identity, survival and corrections are excluded. Missing advance codes use
genuine current-only models. Examined history remains exposed retrospective
evidence, not independent prospective confirmation.

## Population and fitting boundaries

Company identities are resolved separately for package distributor, drug
distributor and authorisation holder through the applicable registry edition.
Aliases, joint entities, unresolved mappings and parallel-import evidence remain
explicit. Today's name cannot establish a historical role.

The eligibility interface separates recommendation exclusions, training-target
exclusions and market-peer exclusions. The latter two default to false. Sources
and supported market peers remain unchanged. A lagged alternative uses supported
premium and stability history with explicit minimum-history and missingness
rules. Development-selected flags never rewrite E4 selections. Whole-history
descriptions are distinct from origin-time features.

Compatible E4 predictions and accepted features are reused after key/value and
pin checks. Freshness holds settings and the trailing three-year window constant.
The refreshed direction component uses broader peers; unchanged equal-peer and
package branches retain their named January cutoff. Monetary models use the
accepted equal-peer feature definition.

Tuning tests a small declared set of iteration, learning-rate, depth and
regularisation choices with native categorical handling. Whole tariff periods
stay together. Early stopping, calibration and outer evaluation use separate
chronological blocks. Later fits use development-chosen iteration counts. Every
label must mature strictly before its fitting or calibration cutoff.

MAE retains its median interpretation. RMSE is mean-oriented; Huber is robust,
not automatically an arithmetic mean. Quantiles are not expected returns. Raw
predictions remain beside `max(0, current AIP + raw change)`, with coherent price
and change. Quantiles are sorted before that support adjustment and crossing
frequency is retained. Empirical interval coverage and width include weak price,
history and peer-support subgroups. Evaluation labels and large moves are never
clipped. Bias, aggregate DKK totals, MAE, RMSE and tail concentration are separate.

The longer-horizon target is the unconditional joint event that next AIP exceeds
origin AIP and remains above it at T+2. Both observations must be eligible and
identity-continuous. Actual next-period rises never enter the predictor. Missing
prices, identity breaks and immature horizons are distinct from failed events.
Bounded feature contributions explain model behaviour, not causal effects.

## Financial interpretation

Fixed comparisons include the E4 probability queue, mean-oriented DKK opportunity
and downside-aware ranking. A persistence gate requires the frozen development
criterion. Natural queues may be empty. Matched workloads retain unknown outcomes
without later replacement. A probability control on the same new forecasts
separates ranking changes from refreshed direction forecasts.

Per-pack opportunity, fixed quantity and fixed capital are different views.
Capital allocation uses integer packs, package/group concentration limits and
explicit unallocated cash. These are scenario quantities, not pharmacy orders.
The existing E4 lot ledger supplies common stock, capacity, receipt assumptions
and shared supported-group demand. Receipt timing, sell-through, expiry,
compensation and return credits are explicit assumptions. Cash, acquisition basis,
inventory value, credits, returns and capital cost remain separate; no sales
margin or profit label is invented. Public wholesaler terms are conditional
context, not verified historical or account-specific terms.

Falling-price review, deferral, temporary peaks, stock holding and return/rebuy
remain business mechanisms. Executable quantities and realised value require
dated sales, stock, expiry, receipt/invoice and commercial records. ABC alone does
not establish package demand or zero sales.

## Saved application and operation

The existing research application accepts `--e5 PATH-TO-INDEX`. It verifies saved
pins and displays units, denominators, eligibility, routes and selection reasons.
Outcomes are revealed separately. Page load never fetches sources, opens the live
database, loads models, fits, orders or promotes. E1–E4 remain available.

From the repository root:

```powershell
.venv/Scripts/python.exe -m streamlit run research_dashboard.py --server.address 127.0.0.1 --server.port 8516 --server.headless true -- --e5 ../data/research-e5/index.json
```

Explicit scientific commands use `bef_redbird.research.e5_experiment`,
`e5_results` and `e5_publish`. The private operating entry supplies exact accepted
commands and paths. Do not rerun completed fits or overwrite accepted results.

E5 reuses the immutable assessment/versioned-outcome lifecycle with a new identity,
bundle, calibration and selections. E4 stays frozen. Pending status requires an
actual date/exposure and availability check. Recovery captures research files and
producer code with shared immutable dependencies; an unused restore must replay
predictions and selections with fitting and database access blocked. No full
operating-database copy is required. Scheduling stays disabled and uninstalled;
automatic promotion, ordering, deployment and Git publication remain excluded.
