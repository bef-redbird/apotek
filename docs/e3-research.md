# Bounded advance-classification research

E3 extends accepted E2 without changing its scientific artifacts. Local fitting,
bounded validation selection and historical evaluation are explicitly authorized.
Scheduling, automatic retraining, promotion, ordering, deployment and uploads
remain disabled. [Progress](progress.md) records execution; the private saved run
owns measured results, denominators, failed attempts and acceptance receipts.

For current tariff period T, admitted information is supported earlier/current
information plus separately named ABC for the actual next tariff period T+1.
Current ABC is never replaced. Unpublished T+1 AIP is a later label; ABC for T+2
or beyond, future groups, attributes, prices and existence states are excluded.
Training labels must mature strictly before each fitting cutoff.

The proxy uses final recorded next ABC, assuming it matches an early report.
It proves neither publication timing nor actual Cito accuracy. Extraction begins
with origin candidates and reads all retained next classifications independently
of price eligibility or outcomes. Missing codes retain candidates; ambiguous
identity and unsupported classifications suppress only ABC. Detailed rejection
states are audit metadata. Only the code, with a generic missing category, enters
models. Final-source absence can still reveal later coverage or disappearance;
the conditional proxy assumption must remain visible.

The frozen sensitivity grid covers perfect matching, missing/incorrect codes,
group-correlated errors and complete removal of usable advance codes. Perturbations
affect prediction only; training uses the unperturbed proxy. Identical seeded
row/group errors apply across methods. These are stress scenarios, not measured
report accuracy. True outcome labels never change.

The finite matrix retains three recent fitting years and E2's modest settings.
Package, equal-size and supported broader-peer CatBoost features each receive
current-only versus advance ABC; logistic regression uses the same equal-size
information contrast. Exact compatible E2 predictions are reused after contract,
key and outcome checks. All examined history remains retrospective development
evidence. Validation selects monetary formulation and queue parameters before
annual evaluation. No expanding-history search or evaluated-subgroup selection
is allowed.

Broader peers start with accepted dated LMS04 membership. Scalar native quantities
require corroborating package descriptions and the same edition's unit dictionary.
Exact same-unit ratios express peer AIP at the focal quantity; fractional ore
remain explicit. Different units, complex packs and unsupported quantities stay
unknown. Denominators disclose omitted native members. This does not establish
clinical substitution or equate AIP, dispensing and reimbursement prices. Fixed
routing uses supported broader peers, then equal-size peers, then package-only
predictions according to origin support, never later outcomes.

Monetary candidates enforce nonnegative next AIP through a predefined support
rule. Predicted DKK change always equals next AIP minus current AIP. Original E2
forecasts, including its invalid-price diagnostic, remain unchanged. Earlier
held-out residuals calibrate empirical intervals in fixed current-price ranges.
Report temporal coverage, width, bias and extreme errors without a theoretical
coverage promise. MAE-loss forecasts are conditional medians, not expected gains;
their sign need not match a separately fitted direction classifier.

Queues retain the original rise top decile and add validation-selected fall-aware
ranking and probability thresholds, subject to a predefined useful workload.
Calibrators use earlier held-out predictions. Natural and matched workloads retain
selected unknown outcomes without replacement. Every evaluated origin has a saved
review containing permitted inputs, probabilities, monetary intervals, support
and selection reasons. Separately keyed outcomes appear only in explicit historical
review. This is a research queue, not an executable purchase list.

The dashboard uses an explicit pinned run index and reconciled E2/E3 comparisons.
Readable names distinguish information, algorithm, peer support, scenarios and
policies. Viewing reads saved JSON and optional review Parquet only; it opens no
live source or model and starts no fitting. Equal-period scores remain distinct
from package-weighted scores, subgroups and exploratory tradeoff curves. Paired
temporal-block intervals do not turn exposed history into an untouched test.

From the repository root, with Python 3.12 and the locked environment:

```powershell
uv run --no-sync streamlit run research_dashboard.py `
  --server.address 127.0.0.1 --server.port 8514 `
  --browser.gatherUsageStats false -- --e3 ..\data\research-e3\index.json
```

Scientific reproduction deliberately starts new local fits; viewing and replay
do not. The private operating entry and acceptance receipt provide captured
producers, pinned inputs, unused-destination commands and research-only recovery.
Never overwrite an accepted directory. Recovery reuses retained R1/E2/source
dependencies without another database copy; it is local existing-interpreter
verification, not off-device or fresh-machine protection.

Sales, stock, expiry, actual acquisition/receipt costs and commercial terms remain
necessary for procurement quantities and realised-profit claims. Prospective
testing needs genuinely recorded pre-outcome access and a fresh exposure lock.
No automatic promotion follows historical results.

The executed comparison finds a substantial conditional advance-information gain,
with smaller additional gains from the model and supported peer features. Missing
codes erode that gain; incorrect and group-correlated codes can reverse it,
especially for monetary predictions. Fall-aware ranking lowers fall exposure at
a matched workload while sacrificing some rises relative to the same-information
rise ranking. Chronological calibration improves one calibration diagnostic but
slightly worsens the primary probability score. Fixed fallback gives a small
overall improvement without selecting evaluated subgroup winners.

Nonnegative amount forecasts improve average error under the proxy assumption,
but extreme errors persist. Earlier-residual intervals have useful aggregate
coverage and narrower widths, with weak coverage for short histories and some
peer-supported groups. Keep the unchanged E2 comparator and treat the E3 models
and queues as conditional research candidates. The next justified action is dated
prospective shadow evaluation of advance-code reliability and the frozen review
policy; combining the best direction fallback with a different queue remains a
separate, untested experiment. Exact measured values and acceptance are private
saved artifacts, with status in [progress](progress.md).
